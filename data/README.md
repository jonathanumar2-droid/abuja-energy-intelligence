# Project Data

This directory contains datasets associated with the Kaduna–Abuja Corridor Energy Intelligence Project.

## Dataset Overview

The initial dataset consists of 17 community energy system records containing information about renewable energy system design capacities.

The available variables include:

- Community identification labels.
- Average daily load figures.
- Total solar PV capacity.
- MPPT capacity.
- Battery storage capacity.
- Inverter capacity.

## Directory Structure

### raw/

Intended to contain original source datasets in their original format.

Original files should remain unchanged to preserve data integrity.

### processed/

Intended to contain cleaned and standardized datasets prepared for analysis.

## Data Sources

The initial figures were compiled from community energy system information made available to the researcher through work involving SOSAI Renewable Energy.

The source, ownership and publication permissions must be confirmed before any original or identifiable project data is released publicly.

## Data Quality Considerations

The current dataset has several limitations:

1. The measurement basis of average daily load requires confirmation.
2. Geographic information is incomplete.
3. Household counts are unavailable.
4. Actual electricity generation and consumption records are not available.
5. Some design dates are inferred from the original community labels.

## Data Handling Principles

- Preserve original source data.
- Document all changes made during cleaning.
- Do not invent missing values.
- Clearly distinguish supplied, calculated and estimated variables.
- Maintain appropriate data permissions and confidentiality.
- Document the source of any additional information collected.
